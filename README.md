# Practical AI for Biomedical Researchers: program and slides

Static page for GitHub Pages. Upload the whole folder contents to a repository
(keep the folder structure), then enable Pages: Settings > Pages > Deploy from a branch > main / (root).

- index.html: the page
- slides/: lecture files linked from the page
- assets/: logo and course illustration

To add slides for a lecture that has none yet (e.g. the introduction or the security lecture),
put the file in slides/ and copy one of the existing button blocks into that row's
<span class="actions"></span> in index.html.
